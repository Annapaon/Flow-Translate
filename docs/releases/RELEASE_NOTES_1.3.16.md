# 1.3.16 数据处理说明分别确认

- 弹窗“翻译前请确认”和设置页“数据处理说明”分别保存本机确认记录。确认一处只隐藏该处，另一处仍须手动点击。
- 两处记录独立于翻译配置，不随导出迁移，也不被导入文件覆盖。旧版本只有一个共用记录，无法确定确认发生在哪一处，因此升级后两处说明均重新显示；既有翻译授权保留。
- 任一处确认仍可授予现有翻译数据处理同意，不新增“两处均确认才能翻译”的门槛。“删除并重置”同时撤销翻译同意并清除两处确认记录。
- 确认保存期间禁用按钮，成功保存后隐藏；失败保留说明并显示可重试提示。
