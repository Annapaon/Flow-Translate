# 1.3.15 按翻译服务能力显示设置

- 弹窗根据划词功能的实际绑定服务显示翻译场景；侧栏根据长文本功能的实际绑定服务显示场景。普通翻译服务显示简短的纯翻译提示，服务切换后自动调整。
- 能力判断复用功能路由，支持统一默认模型、独立绑定、跟随默认及无效绑定回退，并读取实际配置卡片的服务类型。
- 设置页将思考过程、输出模式、翻译场景、智能输出和术语归入“大模型专属设置”折叠区域，列出当前适用的功能。全部使用普通翻译服务时默认收起，仍可展开提前配置。
- 只有全文使用大模型时，隐藏智能输出、输出模式与思考过程，保留场景和术语；全文仍只返回译文。提示词编辑继续保留在原提示词菜单。
- 切换服务不清除偏好，切回大模型恢复已保存的设置；译文“换一种表达”继续按实际请求所用服务显示。

安装包：`.output/flow-translate-1.3.15-chrome.zip`。

验证：类型检查、生产构建和 98 项单元测试通过，ESLint 无错误（7 条存量警告）。浏览器全量运行 55 项通过、1 项旧测试未展开新区域而失败；更新操作路径后该项复测通过，合计 56 项用例均已验证。新增混合绑定覆盖默认机器服务但划词为大模型、侧栏独立切换、仅全文为大模型及跟随默认模型，验证隐藏偏好仍被保留。

安装包完整性、版本、页面入口、图标和 Alt+Q 声明已校验。
