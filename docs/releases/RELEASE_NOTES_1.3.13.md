# 1.3.13 设置界面修复

- **数据处理说明**：未同意时展开；同意后收起正文，保留“数据处理说明 · 已同意 · 点击查看”入口。可重新展开查看或撤销同意。已同意的用户无需再次确认。
- **安全导出**：将“导出包含网站规则”开关移入“导出安全配置”卡片，复用现有开关样式。默认仍不导出网站规则，开关同时适用于包含/不含密钥的导出。
- **输出与场景**：取消默认服务为机器翻译时对智能输出、输出模式、思考过程及翻译场景的禁用。允许预先选择、保存，使用大模型时生效；百度、Google、必应的机器翻译能力不变。侧栏场景在保存或翻译过程中仍临时禁用。
- **快捷键入口**：插件弹窗不再显示“修改快捷键”；设置页保留该入口，弹窗“点击翻译”按钮仍展示实际快捷键。

安装包：`.output/flow-translate-1.3.13-chrome.zip`。

验证：类型检查、生产构建、98 项单元测试和 55 项浏览器测试通过；ESLint 无错误，保留 7 条存量警告。回归覆盖同意说明展开/收起和撤销后的持久化、三家机器服务下的输出与场景设置保存、安全导出开关归组及弹窗快捷键入口移除。

已校验安装包完整性、版本、页面入口、图标和 Alt+Q 声明。
