# v1.2.0 发布说明

本版本面向 Chrome Web Store 与 Microsoft Edge Add-ons 发布准备，重点完成权限、隐私和凭据安全整改。

产品名称同步更新为“流译助手”，英文名称为 “Flow Translate”。

## 用户可见变化

- 首次翻译前显示数据处理说明并要求明确同意。
- 云端模型仅在保存或测试配置时申请对应 API 域名的访问权限。
- 历史记录默认关闭；自动翻译开启时增加确认提示。
- 配置默认不导出 API Key，可单独选择含密钥导出并二次确认。
- 增加“删除全部本地数据”，可清除模型配置、API Key、历史、缓存和统计。
- 模型地址、自定义请求头和导入文件提供更严格的安全校验。

## 安全改进

- 内容脚本与模型凭据隔离，扩展存储仅允许可信扩展上下文读取。
- Gemini 密钥改用请求头传输，避免出现在 URL。
- 强制云端 HTTPS，仅允许 loopback 地址使用 HTTP。
- 增加消息来源与结构校验、流式缓冲上限、错误脱敏和 SHA-256 缓存键。
- 显式限制扩展页面 CSP，确认提交包不包含远程代码。

发布前请完成 `STORE_SUBMISSION.md` 中的发布者检查项，并替换隐私政策联系邮箱占位符。
