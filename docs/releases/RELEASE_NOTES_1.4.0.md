# 1.4.0 功能整合版本

本版本将 `v1.3.0` 之后完成的功能和稳定性改进整合为新的次版本发布。

- 全文翻译支持按键翻译、自动翻译、暂停、继续、恢复原文、失败重试和指定区域翻译；译文在原文下方显示，并可配置字号、间距、底色及配色。
- 双向互译支持选择两种不同语言；划词、全文和长文本可共用默认服务，也可在设置中分别绑定服务。工具栏及长文本页面的服务选择会更新实际调用路由。
- 设置页将划词翻译、全文翻译和长文本翻译拆为三个独立菜单；每个功能分别选择服务、语言方向、提示词风格及适用的输出参数。旧版共享参数会在升级时自动复制到三个功能。
- 增加百度翻译、必应翻译和 Google Cloud Translation v2；移除 DeepL，机器翻译卡片不再显示模型字段或“未配置模型”。
- 增加连接诊断、自动语言预判、网站语言及全文模式规则；网站规则默认不包含在配置导出中。
- 数据处理说明在弹窗和设置页分别确认；导入配置可统一申请必要接口权限并直接启用，通知和错误提示会按时消失并在页面切换后清除。
- 设置写入使用跨页面串行保存和差异合并；降低空闲状态查询频率，优化大型页面首段翻译等待，并拆分设置页及弹窗控制逻辑。
- 删除“换一种表达”及配套撤销流程，保留重新翻译、全文重试和恢复原文。
- 增加配置竞争、服务路由、区域翻译、阅读设置、性能基准、公开网站及真实服务验收工具。

真实百度、必应、Google 账户的连通性、额度、地区网络和译文质量仍需使用发布账户单独验收。公开网站自动化使用本地模拟翻译接口，不代表真实厂商服务通过。

安装包：`.output/flow-translate-1.4.0-chrome.zip`。

验证结果：类型检查通过，103 项单元测试和 58 项浏览器端到端测试通过；ESLint 0 错误、6 条现有警告。生产构建及 ZIP 完整性、1.4.0 版本号、弹窗/设置/侧边栏入口、图标和默认 Alt+Q 快捷键声明均已校验。
