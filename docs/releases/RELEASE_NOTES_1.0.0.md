# 流译助手 1.0.0

1.0.0 是流译助手的首个 GitHub 公开版本。

## 功能

- 划词、网页全文、指定区域和侧边栏长文本翻译。
- 划词双向互译，全文和长文本使用各自设定的目标语言。
- 不同翻译功能可绑定不同服务、语言和提示词风格。
- 支持 OpenAI、Anthropic、Gemini 及常见兼容或本地推理接口。
- 支持百度、必应和 Google Cloud Translation v2 机器翻译。
- 支持全文翻译快捷键、自动模式、网站规则、译文样式及任务恢复。
- 支持配置导入导出、本地历史、缓存和服务用量统计。

## 安装

下载 `flow-translate-1.0.0-chrome.zip` 并解压，在 Chrome 或 Edge 的扩展管理页开启开发者模式，然后加载解压目录。商店版本发布后可直接从对应商店安装。

## 验证

发布前运行 `npm run check`，完成代码检查、类型检查、单元测试、生产构建和浏览器端到端测试。使用 `npm run zip` 生成安装包，并核对清单版本为 `1.0.0`。以最终发布附件的校验值为准。
