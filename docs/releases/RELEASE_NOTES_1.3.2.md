# 1.3.2 更新说明

日期：2026-09-11

- 模型卡片的“测试”结果显示在对应卡片内，支持各卡片独立测试状态，成功/失败信息 4 秒后消失；切换设置菜单立即清除，离开后返回的旧结果不再显示到新页面。
- 全文翻译模式名称改为“按键翻译”和“自动翻译”。
- Chrome 快捷键设置中的全文命令描述改为纯中文“翻译当前网页全文”。
- 默认快捷键改为 `Alt+Q`，通过 manifest 在安装时申请注册。浏览器已有自定义绑定、其他扩展或系统快捷键冲突可能影响实际分配；不覆盖用户绑定，未绑定时仍明确提示，并提供修改入口。
- 弹窗按键模式使用大号紫色按钮，显示“点击翻译（实际快捷键）”。快捷键修改后重新打开弹窗或窗口重新获得焦点时刷新显示。点击将启动请求交给网页内容脚本，确认受理后关闭弹窗；暂停/禁用网站、未同意数据处理或已有任务运行时禁用按钮，连接错误时保留面板显示错误。
- 设置页保留快捷键展示和修改入口，不从设置页启动不明确的网页任务。

快捷键注册与用户重设遵循 [Chrome Commands API](https://developer.chrome.com/docs/extensions/reference/api/commands)。

## 验证与并发保护

回归时复查了设置变化期间的并发取消路径，补充“断开端口不再受理旧消息”和“已暂停会话拒绝排队新请求”的后台保护，避免取消后继续启动工作。

64 项单元测试、29 项浏览器用例通过（完整回归 28 项，补充首个请求与后续排队请求交错时的取消用例）。类型检查、生产构建、ZIP 完整性检查通过；包内版本 1.3.2，全文命令默认 Alt+Q，描述为纯中文。已检查模型卡片结果与大号翻译按钮截图。快捷键变化显示测试模拟了浏览器读接口；真实系统按键与冲突分配仍由日常浏览器验证，不宣称无头浏览器已完成实际绑定。
