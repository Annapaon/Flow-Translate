# 1.3.10 阅读体验优化

## 已完成功能

- **服务连接诊断**：设置页服务卡片显示故障原因与处理建议，可展开脱敏错误类别。测试前检查配置和接口权限；区分认证、资源拒绝、参数、限流、明确额度不足、超时和通用网络故障。通用网络错误不推测确定的 DNS、代理或证书根因。
- **指定区域翻译**：工具栏新增“翻译指定区域”。进入网页后指向并点击正文区域，↑ 可选上级区域，Enter 确认，Esc 或取消按钮退出。只翻译选中根节点内的正文，使用全文模型和用量统计；已有任务需先恢复原文，不与全文任务重复插入。
- **自动跳过目标语言页面**：自动任务启动前在本地做有上限的可见正文抽样。目标语言匹配且样本足够时不启动任务，显示跳过状态；正文变化后重新判断。混合或不确定语言回退到逐段处理；双向互译保持按语向翻译，不按全局目标误跳过。手动翻译仍可触发。
- **译文样式**：设置 → 翻译 → 译文样式，调整相对字号、上下间距、预设底色及是否显示底色，支持预览与恢复默认。即时应用到页面译文，不重译、不清缓存、不暂停运行任务。
- **网站规则**：设置 → 翻译 → 网站专属规则，可覆盖主机名对应的语言或互译对及全文模式，可选择包含子域名。精确规则优先，规则不能绕过总开关、同意、暂停或网站访问限制。独立长文本使用全局语言；模型分配仍按功能。网站规则默认不导出，可在数据页明确勾选包含。
- **换一种表达**：划词结果和网页译文支持单次改写；网页入口在“译文操作”折叠区。仅 LLM 提供，机器翻译不会偷偷切换模型。请求携带原文、原译文及固定目标语言，计入实际服务用量，不读取或覆盖普通翻译缓存。保留旧结果直至新结果完成；失败、取消不丢失旧译文，可撤销上一版。不会为得到不同措辞自动重试。

## 兼容与边界

- 旧配置补齐默认样式和空网站规则，导入对数值、主机名、规则重复及互译语言做校验。沿用 1.3.9 的 DeepL 移除迁移。
- 不增加扩展权限、云端账号或远程代码。区域翻译继续排除表单、隐藏内容、跨域 iframe 等不可处理区域。
- 整页语言判定属于有限抽样，不保证覆盖所有页面内容；使用手动触发可覆盖误判。
- 配置只保存主机规则，不保存完整浏览记录。改写不建立持久化版本历史，网站规则和改写的数据处理已同步隐私政策。
- 本轮未执行真实厂商账户联调或 Chrome/Edge 多系统人工验收。自动化中的厂商接口使用本地模拟服务。
