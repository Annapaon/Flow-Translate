# 1.3.21 稳定性、性能与工程优化

- 配置写入使用跨页面事务锁；只合并用户实际修改的字段，保留其他页面刚保存的配置。划词、全文、长文本服务选择使用同一事务接口。
- 区域和全文翻译明确区分未启用、未同意、网站暂停或受限、页面未就绪、嵌入框架及不支持的页面；连接错误不再反复弹出，恢复后清除旧提示。
- 全文状态查询按任务状态调整频率，空闲从 700ms 降至 5s；失败退避到 10s，隐藏时停止后续查询，重新获得焦点立即刷新。
- 规划语言时限制采样范围；待翻译段落排序每轮仅测量一次位置；状态统计合并为一次遍历。重试成功后不残留旧失败提示。
- 拆分设置页的提示词、翻译配置、模型卡片及弹窗全文会话逻辑；弹窗和长文本共用保存反馈，错误/保存结果 4 秒后消失。
- 增加跨页面并发保存、凭据保留、具体错误原因、查询降频测试，以及性能对比、公开网站 DOM 和真实服务验收工具。

基准数据与验收范围见 [优化验收报告](../reviews/OPTIMIZATION_1.3.21.md)。真实服务需提供专用测试配置，缺少凭据时不会发送请求，也不会记为通过。
