# 使用说明

Firefox 桌面版的安装方式见 [Firefox 说明](FIREFOX.md)。

## 初次配置

1. 点击浏览器工具栏中的流译助手图标，再点击右下角设置按钮。
2. 在“模型服务”中新增大模型或机器翻译服务，填写接口信息后测试并启用。
3. 在“划词翻译”“全文翻译”和“长文本翻译”中分别选择服务、语言及适用设置。
4. 首次发送文本前，阅读并确认弹窗和设置页各自的数据处理说明。

云端服务使用 HTTPS。本机或局域网推理服务可以使用 HTTP，保存或测试时浏览器会申请对应地址的访问权限。

## 划词翻译

在普通网页中选中文字，点击选区旁的小圆点开始翻译。划词设置支持点击或自动触发、字符范围、双向互译、智能输出、输出模式、思考过程和提示词风格。

双向互译只用于划词翻译。开启后必须选择两种不同语言，扩展会根据选中文本判断本次翻译方向；判断不确定时可以在结果浮窗中切换方向。

## 全文与区域翻译

Firefox 的快捷键在 `about:addons` → 齿轮菜单 →“管理扩展快捷键”中修改。

全文翻译默认使用按键模式。按 `Alt+Q`，或点击插件弹窗中的“点击翻译（Alt + Q）”按钮开始翻译。浏览器可能因为快捷键冲突不接受默认绑定，可在“设置 → 全文翻译 → 设置快捷键”中查看和修改实际绑定。

自动模式会在符合网站规则的普通网页中启动。译文显示在对应原文下方，可以暂停、继续、重试失败内容或恢复原文。指定区域翻译只处理用户框选并确认的网页区域。

浏览器内部页、扩展商店、PDF、跨域 iframe、封闭 Shadow DOM 或禁止脚本注入的页面可能无法翻译。

## 长文本翻译

从插件弹窗打开长文本侧边栏，输入文本并开始翻译。长文本使用自己设置页中绑定的服务、语言和提示词风格，不使用划词翻译的双向互译设置。

## 服务与提示词

大模型服务支持 OpenAI 兼容接口、Anthropic 兼容接口、Gemini，以及 Ollama、LM Studio、Xinference、vLLM、SGLang 等本地或兼容服务。机器翻译支持百度、必应和 Google Cloud Translation v2；这些服务需要各自的开发者凭据。

提示词只对大模型服务生效。机器翻译服务不使用智能输出、输出模式、思考过程或提示词风格，相关控件会根据当前绑定服务自动隐藏。

## 配置与本地数据

配置管理支持安全导出和完整导出。安全导出默认排除 API Key、自定义请求头及网站规则；完整配置可能包含敏感信息，不应提交到 GitHub 或发送给他人。

历史记录默认关闭。启用后最多保存最近 100 条记录；缓存默认保留 7 天。设置页可以清除历史、缓存、使用量和本地配置。
