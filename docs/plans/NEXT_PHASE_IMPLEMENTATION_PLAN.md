## 3. 语言方向与轻量翻译行为

### 3.1 双向互译

- 每个功能的 `featurePreferences` 都保存语言方向；`bidirectional` 默认关闭，`pairSourceLanguage` 与 `pairLanguage` 分别表示语言一和语言二，默认“简体中文 / 日本語”。顶层同名字段继续镜像划词配置，以兼容旧配置和旧调用路径。
- 两种语言都可以修改，不能相同。开启时替换原源/目标语言选择框，关闭时恢复原设置值。
- 旧配置缺少语言一时补为简体中文，保留原互译语言；无效或重复的选择由设置归一化处理。
- 可靠识别为语言一时译为语言二；语言二译为语言一。其他语言或无法可靠确定方向时回退语言一，并在需要时提示方向不确定。
- 划词和长文本可切换本次翻译方向；本次显式目标优先于自动判定。

判定使用 `browser.i18n.detectLanguage`、假名等文字特征及 `lang` 提示；短词、全汉字日语和混合语种可能存在歧义。没有为每段另发云端语言检测请求。实际语言解析位于 `src/core/translation/language.ts`，并在生成缓存键及请求之前完成。

双向互译是方向规则，不是独立的模型用途：划词互译使用划词模型，长文本互译使用长文本模型。全文根据页面样本文本确定一次目标语言，任务内统一目标，并跳过可靠识别为目标语言的段落。

插件弹窗的全文控制区不重复显示目标语言；全文语言在“设置 → 全文翻译”中配置，也可被网站专属规则覆盖。协议仍支持本次任务显式目标参数。

### 3.2 智能输出和术语

划词和长文本各自的 `smartOutput` 默认关闭，仅在该功能选择纯翻译模式时启用自动判定；显式选择解释、词汇或语法模式时保留用户选择。当前以 `Intl.Segmenter`、文本长度及句子标点作启发式判断，不宣称具有完整语义分析能力。

全文强制纯翻译并关闭思考过程。机器翻译只发送其支持的参数，不会为了解释、思考或术语转用另一个服务；已保存的 LLM 设置会保留。1.4.0 起，三个功能页根据各自实际服务显示提示词和输出选项；机器翻译隐藏不支持的配置，切回大模型后恢复该功能原有选择。

术语最多 100 条，包含源词、目标词、源/目标语言及保留标记。仅将当前文本中命中且方向匹配的条目注入 LLM Prompt；拉丁文本匹配考虑词边界。规则不自动逆向应用，也不对译文无条件替换。机器翻译原生术语库及可靠占位符术语适配未实现。

### 3.3 重新翻译和网站控制

重新翻译使用新的 `requestId` 和 `refresh: true`，取消原请求、清空旧流式结果，跳过缓存读取并在成功后更新缓存。划词浮窗已移除服务下拉菜单，使用设置中分配的模型；不再描述为可在浮窗临时切换服务。全文“重试失败段落”只重新调度失败块。

网站会话暂停保存到 `storage.session`，永久禁用使用独立 local 域名列表，两者与原黑名单/白名单共同生效，不随模型配置文件迁移。站点暂停/禁用会阻止新翻译并清理网页译文；解除禁用不会自动绕过仍有效的其他访问规则。自动全文模式下，恢复可用条件后可能按模式重新启动，不能承诺恢复站点后一律等待手动点击。

## 4. 模型管理、默认模型与功能分配

### 4.1 默认模型

`activeModelId` 表示默认模型。工具栏选择模型或在设置页卡片点击“设为默认”均自动保存；当前模型显示默认标记及“当前默认”，停用模型不能设为默认。新增并启用模型时沿用现有逻辑，可成为当前默认项。

卡片继续管理服务参数、测试、启停和使用量。“API Key 保存方式”与卡片区域留有独立间距。模型测试结果显示在发起测试的卡片内，各卡片独立计时和清除，点击“设为默认”不会打开编辑弹窗。

### 4.2 按功能分别设置服务

总开关放在“设置 → 基本信息”，具体服务选择放在三个翻译功能的设置页。“模型服务”只负责新增、编辑、测试、启停、统计和设置默认服务：

| 字段 | 默认值 | 行为 |
| --- | --- | --- |
| `separateModels` | `false` | 关闭时所有功能使用默认模型，并隐藏绑定区 |
| `featureModels.selection` | 空字符串 | 划词、右键选区及选区快捷键使用的模型 |
| `featureModels.page` | 空字符串 | 网页全文翻译模型 |
| `featureModels.longText` | 空字符串 | 侧栏长文本翻译模型 |

开启后每个功能页可选择已启用服务，空值表示“跟随默认服务”，并显示默认服务名称。关闭后保留有效绑定，再次开启恢复。删除或停用服务会清理对应绑定并回退默认项；卡片列出绑定用途和回退说明。

`featurePreferences.selection/page/longText` 分别保存源语言、目标语言、互译语言、提示词风格，以及适用于该功能的智能输出、输出模式和思考过程。划词页另含触发方式与字符范围；全文页包含总开关、按键/自动模式、快捷键、译文样式和网站规则；长文本页保存其独立语言及输出偏好。提示词页面只维护四种风格的模板，模型服务页面只维护服务资源。

改变默认模型不修改显式功能绑定。`settingsForFeature()` 以请求副本同步替换服务类型、地址、密钥、模型名、温度、超时、输出预算和请求头，后续缓存、权限、统计及并发都使用实际配置。长文本入口根据扩展侧栏页面地址识别，不能通过待翻译正文指定任意接口。

1.3.11 起，长文本页模型选择框允许直接修改：统一模式下切换默认模型；分功能模式下只修改长文本绑定，可选“跟随默认模型”，保留其他功能绑定。仅在保存或翻译进行中临时禁用选择。双向互译没有第四个模型绑定项。1.3.18 起弹窗划词和全文选择框同样更新对应绑定，支持跟随默认；统一模式下三处选择均修改共享默认服务。全文现有任务保留原快照，新服务用于恢复原文后重新开始的任务。

### 4.3 运行中任务与设置变更

全文启动时保存模型及方向快照。只修改 `separateModels` 或 `featureModels` 不会打断已有全文任务，新分配对后续任务生效。模型参数、默认项、语言配置或访问规则等其他相关配置变化仍沿用暂停保护，继续时重新读取配置，避免静默混用结果。

## 5. 第三方服务与数据结构

### 5.1 已接入服务

| 服务 | 默认地址与凭据 | 当前协议能力 |
| --- | --- | --- |
| 百度翻译 | `https://fanyi-api.baidu.com/api/trans/vip/translate`；App ID、Secret | POST form，MD5 签名；单块纯文本、自动源语言；多行响应合回当前块 |
| Microsoft Translator（必应） | `https://api.cognitive.microsofttranslator.com/translate`；Key、按资源填写 Region | JSON 文本数组，`api-version=3.0`，`textType=html/plain` |
| Google Cloud Translation Basic v2 | `https://translation.googleapis.com/language/translate/v2`；API Key | `q` 数组、语对与 HTML/text；通过 `X-Goog-Api-Key` 发送密钥 |

这些是用户自行开通的开发者 API。当前没有接入免密钥的谷歌旧接口、网页抓取或内置共享密钥；Google Advanced v3、原生术语库和开发者运营的代理服务均未加入。

语言代码及厂商响应在 `src/core/services/machine.ts` 转换和校验。响应数量不匹配、空结果、认证/配额及限流错误有对应处理，错误展示前脱敏。三家服务的协议及扩展链路已使用模拟接口验证；真实账户额度、地区访问等仍需单独联调。

### 5.2 持久化兼容决策

当前继续沿用 `ModelProfile`、`modelProfiles`、`activeModelId`，不创建第二份独立服务列表。`schemaVersion` 为 3，用于迁移按功能保存的 `featurePreferences`；旧版共享偏好会复制到三个功能。`kind`、`appId`、`region`、`maxConcurrency` 等服务字段保持兼容，百度 Secret 使用现有 `apiKey` 通道。

`src/shared/settings.ts` 负责唯一归一化入口，并将默认模型参数同步到兼容顶层字段。模型 ID、local/session 密钥方式和原有导出格式继续兼容。机器翻译允许模型名为空，UI 隐藏不适用字段；持久化结构仍可保留这些兼容参数，不采用最初草案中的独立 `credentialRef` 或服务 discriminated union。

导入采用 Zod 字段校验及按服务补充验证。默认导出剥离 API Key 和自定义请求头，含密钥导出仍需明确确认。公有设置仅暴露界面所需的名称、规则等数据，不暴露接口凭据；内容脚本不能提供任意转发 URL。

## 6. 接口权限与导入并启用

保存、测试和导入统一使用 `src/shared/api-permissions.ts`：仅请求配置接口所需的主机权限，不申请所有网站的必需 API 访问权。插件自身的“是否继续授权”对话框已取消，Chrome 必要提示仍由浏览器显示；已有权限无需重复确认。

导入路径：

1. 选择 JSON 文件，限制文件大小并校验配置；此时不覆盖现有设置。
2. 展示文件及模型数量，用户点击“导入并启用”。
3. 在按钮事件中直接发起权限申请，前面不等待文件读取、存储或权限查询，以保留用户操作上下文。
4. 合并已启用模型的接口主机；停用模型不额外申请。如果全部模型停用，按归一化规则处理首个模型。
5. 授权成功后按保存队列写入配置；不必再逐张卡片保存或测试。拒绝时保留原配置，可直接重试。

导入文件里的隐私同意标记不可信。当前 UI 保留本机已确认的数据处理同意，首次使用可在导入区域明确确认；不再要求每次导入都撤销本机已有同意。配置启用了自动全文模式时，导入并启用后可能开始处理符合规则的页面。缺少有效密钥或接口不可用时，导入成功不等于服务调用成功。

切换设置页面、取消或重新选择文件，会废弃尚未提交的旧导入；双击不会重复启动导入，晚到的授权或文件读取结果不能覆盖新操作。

静态主机权限仅包含本机 HTTP 地址 localhost、127.0.0.1、::1；其他地址按需申请。云端地址必须 HTTPS，HTTP 仅允许符合校验的本机和私有局域网地址。权限按主机合并，不把不同路径或端口当成独立站点。授权不会自动发起模型测试或向开发者上传配置。

## 7. 全文翻译交互与页面实现

### 7.1 开关、模式和快捷键

- `pageTranslationEnabled` 默认 `true`，工具栏与设置页均可开关；关闭后取消任务并恢复原文。
- `pageTranslationMode` 默认 `manual`，界面名称为“按键翻译”；另一选项为“自动翻译”。
- 全文命令 `translate-page` 的默认声明为 `Alt+Q`，描述为纯中文“翻译当前网页全文”。Chrome 决定实际绑定；冲突或已有用户设置可能影响结果。
- 工具栏按键模式显示大号“点击翻译（实际快捷键）”，从 `browser.commands.getAll()` 读取；点击受理后关闭工具栏，网页控制器继续任务。
- 设置页只展示快捷键和修改入口，不从设置页启动不明确的网页。`chrome://extensions/shortcuts` 是实际绑定的修改位置。
- 1.3.8 已删除“默认 Alt + Q；如有冲突，请重新绑定。”提示，但保留未绑定状态和“修改快捷键”，不伪造默认键已经生效，也不添加绕过浏览器设置的网页键盘监听。

全文区域不显示独立的模型选择、目标语言选择或用量估算。任务期间保留完成/总数、失败、跳过、格式降级计数，以及暂停、继续、恢复原文和失败重试。使用量统一在模型卡片中查看。

自动模式在符合网站规则、已经同意数据处理的普通主框架网页上启动，处理 SPA 导航和晚加载正文；不自动滚动、展开折叠内容或抓取未加载的下一页。用户暂停或恢复原文后，不立即在同一页面重新自动启动。

### 7.2 发现可翻译块与对应关系

`collectGroupsAsync()` 分片遍历可读 DOM，将段落、标题、列表项、引用、表格单元格等组成独立语义块，避免父子重复收集。排除脚本、样式、表单与编辑区、隐藏文本、代码块、媒体、导航/按钮、不翻译标记及扩展宿主。

块保存随机 ID、`Group`、序列化原文、状态、宿主引用和变化次数。页面侧使用 anchor、原文结构比较、扫描版本及 `epoch` 阻止陈旧回填；实际协议并未增加独立的 `sessionId/blockId/revision` 全套字段，而是使用独立 Port 会话与 `requestId`。

源文变化只替换对应块；节点消失时释放引用。频繁变化或不支持的布局块会跳过。相同文本仍在不同位置拥有独立块身份，缓存可复用译文，但不能猜测批量返回的对应关系。

### 7.3 原文下方插入与格式

译文使用带 `data-flow-translation` 标记的 `span` 宿主，在合法锚点后以块级正常流显示，内部用 Shadow DOM 隔离。列表在当前项原文后插入，表格在单元格内插入，原 DOM 不替换或整体重建。当前对 Flex/Grid 等难以安全放置的块采取保守跳过，不承诺自动适配所有复杂卡片。

宿主复制字号、字体、字重、行高、对齐等受控排版属性，并使用浅紫底色、细边框和约 9px 圆角区分原文。主题及窗口变化会更新样式。不同语言长度不同，不承诺相同换行、高度或像素级一致。

行内结构转成最小 HTML：常见粗体、斜体、下划线、换行和 span。链接地址与代码占位映射留在本地；`parse5` 解析服务结果后检查标签和 `data-ft-id`，再通过 DOM API 重建。服务生成的新 URL、事件或任意样式不能进入页面；代码从本地映射恢复。结构错误退为安全纯文本并计入格式降级。

百度使用纯文本。LLM、Microsoft、Google 走 HTML 能力路径；LLM 不再统一归入“只能纯文本”的分支。恢复原文只移除当前控制器持有的宿主，保留网页原节点、事件和运行状态。

### 7.4 任务状态、消息和恢复

页面任务状态实际为 `idle / starting / running / paused / completed`，块状态为 `pending / running / done / failed / skipped`。部分块失败不等于整页失败；恢复原文回到 `idle`。

独立 `page-translation` Port 通过 `page-start` 初始化快照，再发送 `translate` 和 `cancel`。服务事件使用 `start / delta / reasoning / retry / finish / error`；开始事件携带实际语言、服务名、HTML 能力及页面并发提示。划词和侧栏使用 `translation-stream`。

暂停中止未完成工作、移除预览并保留成功译文；恢复时重连并处理仍有效的未完成块。断线会暂停，不能假设 Port 能使 MV3 Service Worker 永久在线。路由变化、页面退出、恢复原文和访问规则变化有清理路径。

初始处理预算为 100,000 原文字符，达到后暂停，继续可扩充预算；这是产品处理预算，不是厂商计费额度。MutationObserver 忽略扩展宿主变化，配合版本检查及变化次数上限防止反复翻译。

## 8. 并发、合批、流式与资源保护

### 8.1 模型并发与请求优先级

“设置 → 模型服务 → 编辑卡片 → 高级设置”提供 `maxConcurrency`，默认 2，范围 1–6。前端根据模型设置准备块，后台限制实际网络请求；一个批次只占一个请求槽。

调度键包含接口 origin、凭据和模型配置 ID 的哈希。同一配置被划词、全文、长文本和连接测试使用时共享上限；不同配置独立，不宣称多个配置使用同一账户时已自动共享厂商总配额。

交互请求优先于排队中的全文请求，已发出的请求不被抢占。百度强制单并发，发起间隔至少 1.1 秒；其他服务保留 100 毫秒间隔。429（含百度 54003）触发队列冷却及并发降低，尊重 Retry-After，成功后逐步恢复。翻译重试有界；致命认证或配额错误停止排队工作。

### 8.2 短段落合批与流式预览

| 项目 | 当前实现 |
| --- | --- |
| 合批窗口 | 同一页面 Port 内等待约 20ms，不跨页面或隐私上下文 |
| 单批规模 | 最多 4 段；单段不超过 800 字符；总量受 2400 字符及 LLM 输出预算约束 |
| 合并条件 | 模型、语言、有效配置、术语/Prompt 及格式一致；长段、低输出预算等使用单段路径 |
| 机器翻译 | Microsoft、Google 使用原生数组；百度不合并独立块 |
| 大模型 | JSON 行 `{id,text}`，校验 ID、重复、缺失、空值与大小，按 ID 返回对应段落 |
| 格式不兼容 | 清除预览，退回单段请求，本次页面会话停止新合批 |
| 部分取消 | 仅取消该段接收，其他段可继续；批内全部取消则中断共享请求 |
| 调度顺序 | 每次补充工作时视口内优先，其他块按距视口的距离排列 |
| 提前显示 | 单段流式输出约 80ms 节流预览；批量收到完整可校验 JSON 行后即可预览 |

这替代了最初“必须等待完整块才显示”的设计。预览仍经过安全渲染，重试、取消或失效时清理；仅完整成功的结果进入缓存。合批可能降低请求开销，但不承诺真实服务固定提速倍数。

长文本按内部预算拆分：机器翻译约 1800 字符、LLM 约 8000 字符，尽量在句界/空白处分段并有溢出保护；HTML 保持结构并限制块大小。这些是实现中的保守阈值，不是对全部厂商官方限额的完整元数据建模。

### 8.3 缓存、历史与用量

有效缓存键以 SHA-256 摘要隔离原文、实际模型/接口/凭据、语对、Prompt、术语及影响输出的参数。全文和非全文使用不同前缀，HTML/text 分开；不在键中明文保存密钥。划词与侧栏使用非全文缓存，全文按约 10 MiB、7 天 TTL 和 LRU 独立清理，避免挤掉原有约 100 条非全文缓存。

全文不逐段写入普通历史。历史和收藏保留原有行为；在可识别的隐身标签页上下文中不持久化历史、缓存和用量。

模型卡片分别显示成功完成数、输入/输出字符和真实 API 尝试次数。一次合批可能完成多段，但仅按实际网络请求计 API 尝试；缓存命中不计新 API 调用，已经发生的失败或取消调用仍计数。连接测试归入实际测试卡片，草稿未保存时不冒充已有卡片统计。这些是本地估算统计，不是厂商 Token 账单。

后台在异步读取后、发送前、缓存和历史写入队列中检查取消；端口断开或会话失效后拒绝迟到请求。已提交的成功数据不因随后关闭界面而回滚，不能承诺网络重试 exactly-once 或取消后服务端不计费。

### 11.2 服务连接诊断

**入口与行为**：沿用设置页服务卡片的“测试”按钮。结果继续显示在被测试卡片内，概括为“问题原因 + 一步处理建议”；详细信息按需展开。仍遵守现有反馈超时与切换页面清除规则，不增加常驻告警面板。

**实现路径**：

- 在 `src/core/providers/errors.ts` 与机器翻译适配中统一结构化错误类别：未配置、缺少访问权限、认证失败、资源权限不足、请求参数不支持、限流、额度不足、超时、网络失败和服务端异常。补充 `code`、`retryable`、`retryAfter` 等可选信息，经现有消息通道传到卡片。
- 测试前本地校验参数并检查已有接口权限；确需权限时复用按钮点击触发的原生授权流程。授权失败立即停止，不重复弹窗或请求无关主机。
- 服务商明确返回的错误码优先于 HTTP 状态。例如不能将所有 403 都归为密钥错误，也不能把所有 429 都归为余额不足。
- 浏览器 `fetch` 的通用失败无法可靠区分 DNS、代理、TLS 等原因，展示“网络连接失败”，只提供可能的排查方向，不伪造根因。
- 最多执行现有最小连接测试请求，不自动尝试其他账号或服务；所有实际调用继续计入对应服务卡片。详情只包含脱敏状态与错误分类，不展示请求正文、密钥、自定义请求头或完整响应。

**验收标准**：模拟未授权、401、403、429、超时与网络错误，原因和建议正确且不泄密；限流可展示已知等待时间；配置未通过本地校验时不发送请求；反馈只出现在对应卡片，重复测试、删除卡片和导航后不回填过期结果。真实服务另行验证错误码映射。

### 11.3 指定区域翻译

**入口与行为**：在工具栏全文翻译区域增加次级“翻译指定区域”入口。点击后收起面板，在网页上高亮候选区域，点击确认，Esc 取消。首版采用点选语义区域，↑ 可选择上级，Enter 确认、Esc 取消；暂不增加矩形框选或多区域编辑器；提示可进一步选择包含多个段落的上级正文区域。

**实现路径**：

- 在 `src/content/page-translation/` 增加区域选择器，复用现有 DOM 分组与翻译控制器，使内容收集可接收限定根节点。选择器高亮层不参与正文采集，退出时移除事件监听与节点。
- 捕获确认点击，避免同时触发网页链接或划词翻译；选择期间暂时抑制划词触发，结束后恢复。导航、总开关关闭、页面暂停或禁用时撤销选择。
- 默认使用“全文翻译”绑定的模型及其目标语言规则，不新增第四种模型绑定。缓存、请求调度、取消和模型用量沿用全文通道。
- 同一页面只允许一个全文或区域任务。若已有任务，提示先恢复原文，再选择区域，不启动两套重复插入译文的控制器。复用已完成段落的缓存及恢复原文逻辑，避免同一块重复翻译。
- 动态新增节点仅在已确认区域内参与处理。根节点被移除或路由切换时结束任务；表单、隐藏节点、密码输入、扩展 UI、跨域 iframe 和不可访问 Shadow DOM 继续排除。

**验收标准**：选中区域外不发生翻译请求或 DOM 插入；链接点击不误跳转；Esc 和导航后无残留层或监听器；区域内译文保留行内格式，取消与恢复不影响原网页；沿用模型分配、缓存和统计；与自动全文及划词触发不重复执行。

### 11.4 自动跳过目标语言页面

**能力边界**：这是对现有“逐段跳过目标语言”的启动前优化，不重新开发同一能力。固定目标为中文时，中文页面可跳过，日语页面自动翻译，中日混合页面继续按段落判断。开启中日双向互译后，中文页面可能应翻译成日语，不能因为它是中文就直接跳过。

**实现路径**：

- 自动模式启动前，通过 `src/core/translation/language.ts` 与 DOM 采集模块对少量可见正文做有上限的本地抽样；`html[lang]` 只作为辅助信号，不能独立决定跳过。不调用模型做语言检测。
- 按当前有效配置先确定互译方向及页面目标，再判断是否有需要翻译的内容。只有抽样量足够、判断可信且未发现需翻译内容时，才标记为“页面已是目标语言”并跳过启动。
- 短页面、语言不确定或混合语言场景退回现有按段处理；保留手动触发以覆盖抽样误判。跳过状态不计入模型调用量，不写成用户暂停或永久禁用。
- 为跳过状态保留轻量的路由和正文变化观察，防抖后重新抽样，避免 SPA 或懒加载出现外语正文后一直不翻译。目标语言、互译设置与网站规则改变时使判断失效。

**验收标准**：覆盖中文、日文、混合语言、正文不足、错误 `lang`、互译开启及 SPA 切换；判定跳过时请求数为零，手动触发仍可用；新出现的外语正文可以触发复查；比较优化前后的扫描耗时和请求数，不承诺固定速度倍数。

### 11.5 译文样式设置

**入口与行为**：在设置页的全文翻译配置内增加折叠的“译文样式”，不在工具栏重复配置。默认保持现有浅色圆角框；提供相对字号、预设底色、上下间距、“显示底色”开关及恢复默认，并在设置区提供静态示例预览。

**实现路径**：

- 新增有范围限制的样式配置，经 `src/shared/types.ts`、`settings.ts`、导入校验和公共设置同步到内容脚本；只接收数值、布尔值和预设枚举，不允许导入任意 CSS 或 HTML。
- 使用译文 Shadow DOM 的 CSS 变量控制表现，字号相对原文，保持标题、列表与行内强调的原有继承。关闭底色不移除译文，也不改变原文样式。
- 设置变动直接更新已插入译文的样式，不发起重译、不清缓存、不更换模型。调整全文设置快照比较，避免纯样式变更误暂停正在运行的任务。
- 分别提供浅色、深色主题的可读配色；窄屏、长文本与高倍缩放时避免裁剪。无需新配色库或在线主题资源。

**验收标准**：默认外观与现版一致；旧配置正常导入；越界值被校验或规范化；修改样式时请求量不增加、运行任务不暂停；深浅主题可读，恢复默认即时生效，原页面布局与交互不被重置。

### 11.6 网站专属规则

**入口与行为**：在设置页增加折叠的网站规则列表，可新增、编辑、删除规则。每条指定主机名，可显式勾选包含子域名；可覆盖语言配置和全文“跟随全局／按键翻译／自动翻译”。默认没有规则，保持当前行为，首版不增加按网站绑定模型。

**实现路径**：

- 规则保存在本地设置中，包含稳定 ID、主机名、子域名匹配开关和可选覆盖项。固定语向与双向互译分别完整保存；互译必须包含两种不同语言，不能与全局值拼出不完整语言对。
- 用 URL 解析后的规范化主机名匹配，禁止任意正则、用户名、查询参数和路径；明确区分精确主机与子域名后缀匹配，避免将 `example.com.evil.test` 误匹配为 `example.com`。
- 优先级为：全局功能开关、数据处理同意、网站允许/禁用及会话暂停等准入约束 → 精确网站规则 → 最具体的包含子域名规则 → 全局默认。局部手动切换方向仅影响当次请求。网站规则不能绕过权限和准入约束。
- 对有网页来源的划词、全文和区域翻译先解析网站配置，再套用对应功能的模型分配；独立长文本页没有网页上下文，仍使用全局语言配置。全文任务固定开始时的有效方向，相关规则改变后暂停并等待新任务，避免混用目标语言。
- 网站规则默认不包含在配置导出中，与现有站点敏感配置边界一致。需要迁移时在“导出安全配置”卡片中勾选包含网站规则，导入严格校验；不保存完整浏览记录。规则去重并限制数量，重复导入不叠加同一规则。

**验收标准**：覆盖精确域名、子域名、相似恶意域名、国际化域名、SPA 导航和规则删除；无规则时与当前行为一致；站点自动模式无法绕过总开关或暂停；缓存区分最终目标及有效翻译配置；导出默认不泄露网站列表。

### 11.7 “换一种表达”（已移除）

1.3.20 根据产品精简要求移除划词和网页译文的改写入口、专用请求字段与提示词、改写缓存分支、取消及撤销逻辑。普通“重新翻译”、全文失败重试、恢复原文继续保留。历史方案见 1.3.10 版本说明，不代表当前支持。
