# 1.3.8 更新说明

- 删除设置页和弹窗中的“默认 Alt + Q；如有冲突，请重新绑定。”提示。
- 保留实际快捷键显示、“修改快捷键”入口，以及 manifest 中全文翻译默认快捷键 `Alt+Q`。
- 已核对 1.3.7 包，原有默认快捷键声明并未缺失。Chrome 在安装时尝试注册默认键，其他扩展冲突可能导致未分配；浏览器还允许用户修改或取消绑定。代码不伪造已绑定状态，也不添加独立于 Chrome 设置的网页按键监听。

浏览器中的实际绑定需在 `chrome://extensions/shortcuts` 查看；如同时安装了多个旧版扩展，应检查它们是否占用了该组合键。仅凭项目及安装包无法确认用户浏览器中的具体冲突来源。依据：[Chrome Commands API](https://developer.chrome.com/docs/extensions/reference/api/commands)。

验证：类型检查、2 项快捷键相关浏览器用例通过；生产构建及 ZIP 完整性检查通过，包内版本为 1.3.8，全文默认键声明为 Alt+Q。浏览器用例验证命令触发路径与实际绑定显示，不宣称已确认用户环境中的系统按键分配。
