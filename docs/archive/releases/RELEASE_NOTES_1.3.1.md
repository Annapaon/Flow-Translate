# 1.3.1 更新说明

日期：2026-09-11

- 全文翻译增加独立启用开关，在工具栏弹窗与设置页同步。默认启用、快捷键手动触发，不自动发送页面正文；关闭时取消任务并移除译文。
- 默认快捷键为 `Alt+Shift+T`。设置页显示浏览器实际绑定，并提供“修改快捷键”入口。快捷键由浏览器管理，不写入配置 JSON；导入配置不会改动浏览器的按键绑定。未绑定或快捷键冲突时显示提示。[Chrome Commands 官方说明](https://developer.chrome.com/docs/extensions/reference/api/commands)
- 用户选择自动模式后，进入普通 HTTP(S) 页面或 SPA 新路由时自动翻译；内容延迟加载时也可触发。遵守隐私同意、网站黑白名单与暂停/禁用规则；手动暂停或恢复原文后，不在同一路由重新自动启动。
- 全文翻译使用当前默认服务及翻译语言规则，控制区不再展示模型、目标语言和字符量。划词浮窗仍保留“当前服务”下拉框及临时服务切换。
- 划词、长文本和全文翻译的完成次数、输入/输出字符量及 API 尝试均归属实际调用的配置卡片。已保存配置的连接测试也记入 API 尝试。缓存命中不新增 API 次数；失败、取消和重试计入已经发生的 API 尝试。隐身页继续不持久保存统计，未保存的测试配置不创建虚构模型卡片。统计不是服务商账单或精确 Token 消耗。
- 全文译文增加淡紫底色、细边框、圆角及内边距，继续继承原文排版，恢复原文只删除扩展节点。
- 配置新增 `pageTranslationEnabled`（默认 `true`）和 `pageTranslationMode`（默认 `manual`，可选 `auto`）。旧 JSON 可导入，默认不会自动翻译；导入后仍需重新同意数据处理说明。
- 发布版本从 1.3.0 升级为 1.3.1；后续修复和小改动递增补丁版本，打包文件名与 manifest 保持一致。

## 验证

- 63 项单元测试通过；26 项 Chromium 浏览器用例通过（完整回归 25 项，加模型跨入口统计用例）。
- 类型检查、生产构建与 ZIP 完整性检查通过，包内版本为 1.3.1，manifest 包含默认 `Alt+Shift+T` 命令。
- 浏览器用例验证快捷键对应的消息处理，单元测试验证命令路由及启用/同意门槛；无头测试浏览器未分配实际快捷键，操作系统级按键触发和用户自定义绑定仍需在日常浏览器中确认。界面会明确显示未绑定状态，不把默认建议键冒充已生效绑定。
- 翻译服务验证使用本地模拟接口，不涉及真实账号计费或第三方生产接口联调。
