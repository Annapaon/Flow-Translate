# 1.4.3 提示词编辑与快捷键精简

- 插件弹窗移除划词翻译场景选择；提示词风格继续在设置页的划词、全文和长文本功能中分别配置。
- 删除划词和长文本快捷键命令及设置入口，只保留全文翻译快捷键和 `Alt+Q` 默认建议。
- 提示词卡片改为只读摘要，卡片提供编辑、复制和删除操作，不再直接显示输入框或“大模型生成”按钮。
- 新增和编辑提示词使用同一弹窗。弹窗可选择“手动输入”或“大模型生成”；生成模式要求填写风格名称、风格说明并选择已启用的大模型，生成后可继续修改，确认保存后才写入配置。

安装包：`.output/flow-translate-1.4.3-chrome.zip`。

自动化验证已通过：ESLint（0 个错误）、TypeScript 类型检查、105 个单元测试、60 个端到端测试和生产构建。真实厂商接口仍需使用发布账户单独验收。
