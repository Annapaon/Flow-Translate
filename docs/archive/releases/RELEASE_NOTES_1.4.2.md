# 1.4.2 划词模型识别修复

- 划词、全文和长文本请求统一从当前功能绑定的模型卡片解析服务类型、API 地址、密钥、模型名和请求参数。
- 使用“跟随默认服务”时，直接解析当前默认模型卡片，不再依赖可能尚未同步的旧版顶层兼容字段。
- 划词结果浮窗底部显示“服务配置名 · 实际模型名”；百度、谷歌、必应等机器翻译服务只显示服务配置名。
- 增加回归测试，覆盖顶层兼容字段过期时的默认模型解析、明确绑定模型的请求参数以及浮窗实际模型展示。

安装包：`.output/flow-translate-1.4.2-chrome.zip`。
