# 1.4.4 划词翻译连接修复

- 划词翻译与长文本翻译改用各自明确的后台连接通道，后台不再依赖发送页面地址判断功能类型，确保读取对应功能绑定的服务。
- 划词浮窗在请求建立前即可显示当前绑定的服务名称；百度、谷歌和必应等机器翻译服务只显示服务名称，大模型同时显示实际模型名。
- 扩展更新导致旧网页中的内容脚本失效时，划词浮窗会明确提示刷新当前网页，不再停留在看似持续连接的状态。
- 增加百度、谷歌机器翻译划词调用及服务名称显示的回归检查；大模型划词路由继续覆盖独立模型绑定和实际请求模型。

安装包：`.output/flow-translate-1.4.4-chrome.zip`。

自动化验证已通过：ESLint（0 个错误）、TypeScript 类型检查、105 个单元测试、60 个端到端测试和生产构建。真实厂商接口仍需使用发布账户单独验收。
