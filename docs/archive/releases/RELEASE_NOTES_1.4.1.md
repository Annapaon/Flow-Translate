# 1.4.1 翻译设置与提示词优化

- 双向互译仅保留在划词翻译；全文翻译、指定区域翻译和长文本翻译固定使用各自设置的源语言与目标语言。
- 提示词风格支持新增、删除、重命名和编辑，最多保存 50 种；可以选择已启用的大模型，根据风格说明和补充要求生成提示词，调用量计入对应模型卡片。
- 插件弹窗删除全文翻译服务选择和冗余服务说明，将“翻译服务”更名为“划词翻译服务”；确认数据处理说明后，常规内容可在 600px 高度内完整显示。
- 删除基本信息中的“按翻译功能分别设置服务”开关，划词、全文和长文本始终拥有独立绑定，空值继续跟随默认服务。
- 快捷键状态和“设置快捷键”按钮分别放入三个翻译功能设置页；Chrome 跳转到 `chrome://extensions/shortcuts`，Microsoft Edge 跳转到 `edge://extensions/shortcuts`。
- 新增长文本侧栏命令项，可在浏览器快捷键页面自行绑定；全文和划词继续建议使用 `Alt+Q` 与 `Alt+T`。
- 配置结构升级为 `schemaVersion: 4`；旧配置自动生成四种内置提示词风格，旧全文网站双向规则按原语言二迁移为固定目标语言。

安装包：`.output/flow-translate-1.4.1-chrome.zip`。

自动化验证已通过：ESLint（0 个错误）、TypeScript 类型检查、104 个单元测试、60 个端到端测试和生产构建。真实厂商接口仍需使用发布账户单独验收。
