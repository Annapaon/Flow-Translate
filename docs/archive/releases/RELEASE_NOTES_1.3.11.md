# 1.3.11 服务配置界面修复

本版本在 1.3.10 的代码基础上修复 1.3.9 测试反馈，保留已完成的阅读体验功能。

- **提示词设置**：默认服务为百度、Google 或必应时，仍可打开、编辑和保存提示词。页面明确说明提示词用于大模型，机器翻译 API 不使用这些内容。
- **长文本模型切换**：移除功能绑定导致的永久禁用。统一模型模式下切换默认模型；分功能模式下只更新长文本绑定，并提供“跟随默认模型”。读取最新设置后保存，保留其他功能绑定。保存或翻译进行中临时禁用选择，避免显示服务与正在执行的请求混淆。
- **弹窗服务名称**：百度、Google、必应仅显示配置名称，不附加模型名或“未配置”。大模型保持“配置名称 · 模型名称”的显示。
- **必应名称统一**：中文服务类型改为“必应翻译”，英文为“Bing Translate”；内部 `microsoft` 服务 ID、Microsoft Translator API 地址与鉴权方式保持不变。旧内置配置名“Microsoft / 必应翻译”读取时规范为“必应翻译”，保留其他自定义名称。

验证：`npm run check` 通过，包含类型检查、98 项单元测试、生产构建及 53 项浏览器测试；ESLint 无错误，保留 7 条存量警告。新增 `tests/e2e/service-ui-regressions.spec.ts` 覆盖三家机器翻译下的提示词编辑、弹窗名称、必应名称兼容，以及长文本默认/独立绑定切换、实际请求路由和持久化。

已生成 `.output/flow-translate-1.3.11-chrome.zip`，并校验 ZIP 完整性、版本、页面入口、图标和 Alt+Q 声明。
