# 1.3.6 更新说明

日期：2026-09-11

- 保存、测试模型时取消插件自身的“是否继续授权”对话框，由 Chrome 处理必要的接口权限请求；已有权限无需重复确认。
- 配置管理改为“选择文件 → 导入并启用”。先校验文件，在明确点击按钮时一次性申请已启用模型所需的接口权限，通过后保存并启用配置，无需逐个保存或测试模型。
- 同一主机的接口合并申请，不扩大为所有网站；已禁用模型不申请权限。如果配置中全部模型均禁用，按现有迁移规则为首个模型申请权限并启用。本机 HTTP 静态权限继续复用，HTTPS 本机接口仍按实际权限申请。
- 权限申请直接发生在按钮事件中，前面不等待文件读取、存储或权限查询，确保保留浏览器要求的用户操作上下文。
- 拒绝授权或权限请求失败时不覆盖配置，允许直接重试。切换设置页面、取消或重新选文件会废弃尚未提交的旧导入任务，避免晚到的读取或授权结果覆盖配置。
- 不采用文件里的隐私同意标记；保留本机已经明确确认的数据处理同意。首次使用可在导入区域阅读说明并勾选确认，然后完成导入并启用。导入时提示自动全文模式可能启动，服务仍需要有效密钥及正常网络。
- 导入区域复用现有紫色按钮、圆角容器与错误消息的自动消失行为。

验证包括权限请求同步发起、接口去重、本机权限边界、拒绝与异常、导入后立即翻译、本机同意保留、首次同意不可由文件绕过、页面切换取消旧导入，以及保存与测试不再调用自定义确认框。浏览器用例中的外部接口授权结果通过模拟 permissions.request 验证；Chrome 原生权限弹窗的人工交互未纳入自动测试，不使用用户真实密钥调用外部服务。

验证结果：类型检查、89 项单元测试、39 项 Chromium 浏览器用例通过，导入区域截图已检查。生产构建和 ZIP 完整性校验通过，包内版本为 1.3.6，必需主机权限保持原范围。
