# 1.3.5 更新说明

日期：2026-09-11

- 在“设置 → 模型服务”的卡片上方新增“按功能分别设置模型”，复用原有紫色滑动开关、下拉框和圆角样式；窄屏下按单列排列。
- 默认关闭，所有翻译功能沿用默认模型。开启后显示划词、全文、长文本的模型绑定项；每项支持“跟随默认模型”，并显示默认模型名称。关闭开关时保留绑定，重新开启恢复。
- 工具栏和划词浮窗不增加绑定配置。长文本页已有的模型选择框在单独绑定时显示实际模型并禁用编辑，提示在设置中修改；跟随默认模型时保留原有操作。
- 后台根据翻译入口解析完整模型配置，密钥、鉴权、服务地址、参数、缓存和使用量均对应实际模型；多个功能共用同一配置时仍共享该模型的并发上限。
- 页面翻译启动时固定模型；仅修改功能绑定或总开关不会打断已有任务，后续任务使用新分配。模型配置本身变化、停用、删除、隐私或网站权限变化仍沿用现有暂停保护。
- 停用或删除被绑定的模型后，对应功能自动跟随默认模型；模型卡片列出绑定用途并提前说明回退行为。已停用或删除的模型不再出现在可选列表中。
- 旧配置自动迁移为统一模式，新开关和绑定支持导入导出；导入时清理已不存在或未启用的绑定。连接测试始终测试点击的模型。

验证包括旧配置迁移、绑定开关记忆、导入导出、无效绑定回退、各入口实际模型路由、模型卡片统计、运行中全文任务保持模型、长文本显示与设置区截图检查。

验证结果：类型检查、85 项单元测试、35 项 Chromium 浏览器用例通过。已检查模型分配区域截图；生产构建、ZIP 完整性及包内版本 1.3.5 校验通过。真实第三方服务使用用户凭据联调不在本次自动测试范围内。
