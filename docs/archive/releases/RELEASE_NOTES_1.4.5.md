# 1.4.5 页面翻译交互修复

- 长文本翻译操作区不再显示“正在翻译 / 翻译完成 → 目标语言”等普通状态文字，开始翻译后按钮保持在同一行；调用失败仍单独显示错误信息。
- 页面不支持翻译、没有可读正文或当前访问条件不满足时，提示会持续显示，直到页面状态、活动标签页或操作条件发生变化。
- 指定区域翻译在页面公开配置尚未到达时会等待配置初始化，避免直接返回“页面配置尚未就绪，请稍后重试”。
- 增加长文本布局、不可翻译提示持久化和区域选择回归验证。
