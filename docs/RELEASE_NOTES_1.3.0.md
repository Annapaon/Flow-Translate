# 1.3.0 开发交付记录

日期：2026-09-09。当前为工作区开发版本，尚未提交或发布商店。

## 已实现

- 设置页双向互译开关及互译语言；原固定语向保留。划词、快捷键、右键、侧栏共用后台语言判定，支持本次方向覆盖。
- 可选智能输出与最多 100 条定向术语；机器翻译服务使用纯翻译，保留原 LLM 设置。
- 划词与侧栏重新翻译（绕过缓存），浮窗可临时切换服务。
- Popup 的会话暂停、永久禁用及解除；独立保存域名规则，不修改已有黑白名单。
- 百度、Microsoft Translator、Google Cloud Translation v2、DeepL API 协议适配、服务配置与连接测试。百度 Secret 使用现有 apiKey 凭据通道保存；App ID/Region 单独配置。DeepL 可选 Free/Pro 地址或用户自行管理的兼容网关。
- 全文双语插入、可读文本估算、视口优先调度、进度、暂停/继续、恢复原文、失败块重试；一轮 100,000 字符预算，继续后扩充预算。
- 常见粗体、斜体、原链接及行内代码映射；安全 AST 重建，格式异常时降级为纯文本，不执行服务返回内容。
- 动态内容增量、原节点变化失效、SPA 清理、设置变化和后台断线暂停；DOM 扫描定期让出主线程。
- 共用限流队列，交互请求优先；机器翻译长文本按小批次发送，全文块独立调度。失败重试、Retry-After、取消及权限复核。
- 全文与划词缓存分开淘汰；全文缓存约 10 MiB、7 天 TTL、LRU，全文不逐块写入普通历史。完成统计与 API 尝试统计分开；隐身翻译不持久化这些数据。

## 兼容实现决策

为保留旧导出文件、现有 UI 和稳定的配置 ID，持久化继续沿用 `modelProfiles` / `activeModelId` 字段，增加 schemaVersion 2、kind 和服务专属字段；不另建一份可独立写入的服务列表。机器翻译在统一调度层分流，不经过 LLM Prompt / 模型名校验。

网站临时暂停使用 session 存储；永久禁用使用独立 local 域名列表，解除时不删除用户原有访问规则。配置页“删除并重置”同时清除两者。该独立暂停列表不随模型配置导出迁移。

## 支持范围和待联调事项

普通 DOM 网页为当前支持范围；不支持 PDF、跨域 iframe、封闭 Shadow DOM、图片/公式/代码块翻译。原网页的表单、隐藏内容和可编辑区域不参与全文发送。Flex/Grid 文本若不能在当前布局中安全插入，会跳过该块；不承诺所有网页像素级排版一致。

本地检测对短词/混合语种可能不可靠，可在浮窗或侧栏切换本次方向。术语通过 LLM Prompt 提供，不保证模型严格遵循；机器翻译首版不启用原生术语库。按网站记忆语言对是规划中的可选增强，未加入本版。

四家服务的自动化测试均使用本地模拟接口。没有使用真实账户或真实密钥进行云端调用，因此账户额度、地区访问、真实译文质量、DeepL 扩展直连，以及 Chrome/Edge 多版本的人工抽样仍待真实环境验收。使用者可在服务设置中“测试连接”进行实际联调；测试连接会发送一小段文本并可能计费。DeepL 直连失败时显示错误，只有用户自行配置兼容网关后才经过该网关。
